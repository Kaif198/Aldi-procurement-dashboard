## 🎯 Project Overview

This project delivers a comprehensive procurement performance insights dashboard designed for C-level executives, procurement managers, and strategic decision-makers at ALDI Süd Holding.

### Key Metrics Analyzed:
- 💰 **€8.7B** Total Annual Procurement Spend
- 🏢 **1,847** Active Global Suppliers
- ✅ **94.2%** Supplier On-Time Delivery Rate
- 💡 **€287M** Cost Savings Achieved (FY 2024-2025)
- ♻️ **89%** Sustainable Supplier Compliance
- 📊 **72.4%** Spend Under Contract
- ⭐ **4.6/5.0** Average Supplier Quality Score

## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No server or installation required - runs entirely in browser

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/Kaif198/aldi-procurement-dashboard.git
cd aldi-procurement-dashboard
```

2. **Open the dashboard**
```bash
# Simply open the HTML file in your browser
# On Mac:
open aldi_procurement_dashboard.html

# On Windows:
start aldi_procurement_dashboard.html

# On Linux:
xdg-open aldi_procurement_dashboard.html
```

**Or** double-click `aldi_procurement_dashboard.html` in your file explorer.

### Alternative: GitHub Pages Deployment

1. Fork this repository
2. Go to Settings → Pages
3. Select main branch as source
4. Your dashboard will be live at `https://yourusername.github.io/aldi-procurement-dashboard/`

## 📊 Key Insights & Findings

### Strengths Identified
✅ **Strong Supplier Performance**: 94.2% on-time delivery exceeds industry average (91%)  
✅ **Cost Optimization Excellence**: €287M savings achieved (3.3% rate vs 2.5% industry avg)  
✅ **Sustainability Leadership**: 89% supplier compliance, approaching 100% 2025 target  
✅ **Quality Management**: 4.6/5.0 average quality score above industry benchmark

### Opportunities for Improvement
🎯 **Contract Coverage**: Expand from 72.4% to 80% → **€58M** additional savings potential  
🎯 **Cycle Time Optimization**: Reduce from 7.2 to 5.0 hours → **€12M** efficiency gains  
🎯 **Supplier Consolidation**: Further 5% reduction → **€35M** in volume leverage  
🎯 **Total Projected Impact**: **€105M** in additional annual savings

### Strategic Recommendations
1. Implement RPA for procurement process automation
2. Expand contract coverage in non-food and logistics categories
3. Deploy AI-powered spend analytics platform
4. Accelerate sustainability compliance to 100%
5. Enhance regional sourcing strategies
